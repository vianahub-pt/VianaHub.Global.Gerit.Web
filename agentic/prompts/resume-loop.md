# Prompt de retomada

Leia state, goal, plano e journal. Confirme repo/branch/goal, inspecione diff sem descartá-lo e retome `pending_action`. Orchestrator só coordena; architect planeja; apenas implementer edita arquivos funcionais permitidos; tester/security/reviewer são read-only. Registre controller e actor separadamente. Antes de READY_TO_COMMIT, cada arquivo funcional precisa de provenance do implementer (action, files_changed exato, result PASS); state/journal são isentos. Consulte ai-memory apenas se MCP real estiver disponível. Preserve gates concluídos, quotas, sandbox e limites. Git mutável, PR, merge e deploy são exclusivos do supervisor.
